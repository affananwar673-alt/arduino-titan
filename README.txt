# RoboForge Academy Website

## How to open on your phone
1. Extract the ZIP file.
2. Open `index.html` in a browser or a mobile code editor such as Acode.
3. Edit the academy name, course details, prices and text.
4. Replace the emoji project visuals with your own project photos.

## Important
This is a frontend prototype. The enrollment buttons and contact form are demos.
Before accepting real payments, connect:
- A payment gateway
- A secure backend
- Student accounts and course access
- Video/course hosting
